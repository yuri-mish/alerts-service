Як почати

Усі запити — GET на https://alerts.starsam.net з ключем у заголовку X-Api-Key. Відповідь — JSON (або CSV з параметром format=csv).

curl -H "X-Api-Key: ВАШ_КЛЮЧ" "https://alerts.starsam.net/summary?month=2026-11&region=31"

Ключ безкоштовний — заповніть заявку, і ми надішлемо його на ваш email. Ліміт — 6 запитів на хвилину на ключ; понад нього сервер відповідає 429 із заголовком Retry-After (через скільки секунд можна повторити). Запити з браузера з будь-якого сайту дозволено (CORS).

Ключ, вставлений у JavaScript на сторінці сайту, бачать усі відвідувачі. Для публічних сайтів робіть запити зі свого сервера.

Що означають дані

  • Лише повітряні тривоги. Загрози артобстрілу, вуличних боїв тощо не враховуються.
  • Тривога розрізана по добах. Якщо тривога триває через північ, буде два рядки: до 00:00 і після 00:00 (за київським часом). Тому тривога на межі місяців потрапляє в обидва місяці.
  • Рівень — останній відомий для тривоги (red / yellow).
  • Території: region — область (UID регіону), location — конкретна територія (сама область, район, громада або місто). В одній області тривоги району й громади можуть перекриватися.
  • Час у полях *_local і у вигрузці для 1С — київський; started_at / finished_at — UTC.
  • Тривога, що ще триває, має порожній кінець. Це стан на момент нічного оновлення — бонус до історії; для стану тривог у реальному часі сервіс не призначений.
  • Глибина архіву: з листопада 2026 року.

GET/periods

Список тривог: один рядок на кожну добу тривоги з початком, кінцем, тривалістю в хвилинах і рівнем. Підходить для власних звітів і аналізу.

ПараметрОпис
monthОбов'язковий. Місяць YYYY-MM, напр. 2026-11
regionUID регіону або кілька через кому: 14,31
locationUID території (район, громада): 75 або 75,76
levelred або yellow
formatcsv — файл для Excel (роздільник ;, UTF-8 з BOM)
limitМаксимум рядків (за замовчуванням 50 000)

Без region і location — усі області. Сортування — за початком, далі за територією.

curl -H "X-Api-Key: ВАШ_КЛЮЧ" \
  "https://alerts.starsam.net/periods?month=2026-11&location=75"
const res = await fetch('https://alerts.starsam.net/periods?month=2026-11&region=14&level=red', {
  headers: { 'X-Api-Key': 'ВАШ_КЛЮЧ' },
});
if (!res.ok) throw new Error(`${res.status}: ${(await res.json()).error}`);
const rows = await res.json();
const minutes = rows.reduce((sum, row) => sum + (row.duration_min ?? 0), 0);
curl -H "X-Api-Key: ВАШ_КЛЮЧ" -o alerts-2026-11.csv \
  "https://alerts.starsam.net/periods?month=2026-11&location=75&format=csv"

GET/summary

Підсумок за місяць: кількість тривог і години по регіонах (або по територіях) окремо для кожного рівня та разом (all). Години рахуються з об'єднанням перекриттів: якщо тривога в районі й у громаді йшли одночасно, час не подвоюється. Тривога, що ще триває, рахується до поточного моменту.

ПараметрОпис
monthОбов'язковий. Місяць YYYY-MM
regionUID регіону або список через кому; без region і location — усі області
locationUID території або список через кому
bylocation — розбити підсумок по територіях
curl -H "X-Api-Key: ВАШ_КЛЮЧ" \
  "https://alerts.starsam.net/summary?month=2026-11&region=31"

# по районах Київської області
curl -H "X-Api-Key: ВАШ_КЛЮЧ" \
  "https://alerts.starsam.net/summary?month=2026-11&region=14&by=location"
const res = await fetch('https://alerts.starsam.net/summary?month=2026-11&region=31', {
  headers: { 'X-Api-Key': 'ВАШ_КЛЮЧ' },
});
const rows = await res.json();
const total = rows.find((row) => row.level === 'all');
console.log(`${total.alerts} тривог, ${total.hours} год`);

GET/1c/alerts

Вигрузка для 1С: рядок на кожну добу тривоги з полями кирилицею. НомерТревоги — порядковий номер тривоги в межах території й доби (1, 2, 3…). Час — київський, без часового поясу. Шматок тривоги, що перетнув північ, закінчується о 00:00:00 наступної доби.

ПараметрОпис
monthОбов'язковий. Місяць YYYY-MM
regionUID регіону або список через кому
locationUID території або список через кому
levelred або yellow — лише тривоги цього рівня (НомерТревоги лишається як серед усіх тривог доби)
formatcsv — файл замість JSON

Без region і location — усі області за місяць. Невідомий параметр (наприклад, опечатка) — помилка 400.

Помилки

Тіло помилки — {"error": "опис"}.

КодПричина
400Невірний параметр: місяць не у форматі YYYY-MM, UID не число, не вказано ні region, ні location, невідомий параметр
401Немає ключа, ключ невідомий або вимкнений
403Ключ не дає доступу до цієї команди
404Немає такої команди
429Понад 6 запитів за хвилину — дочекайтеся Retry-After секунд

Джерело даних — alerts.in.ua. Дані надаються «як є», без гарантій повноти й безперервності; не використовуйте сервіс для критичної інфраструктури чи сповіщення про небезпеку. Стан сервісу: /health.
